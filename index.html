What you need

Copilot Studio track

A test Microsoft 365 tenant, a Microsoft 365 Copilot license, Copilot Studio access with Copilot Credits, and a Power Platform environment with Dataverse.

Cowork track

A Microsoft 365 account with Copilot and access to Copilot Cowork. Sample files are provided in the repository.

Copilot+ PC track

A Copilot+ PC with Windows 11 24H2 or newer to run the AI features, plus Git and the .NET 8 SDK. No Visual Studio, no cloud subscription.
